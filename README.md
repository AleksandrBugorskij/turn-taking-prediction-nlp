# Turn-taking Prediction for Chatbot (NLP Contest)

Решение задачи бинарной классификации по определению момента смены реплики в диалоге (Turn-taking Prediction)[cite: 1].

## Стек технологий
- Python, Pandas, NumPy
- CatBoost, Scikit-learn

## Описание решения
- Извлечены поведенческие и текстовые признаки из диалоговых сессий JSONL: количество сообщений, временные интервалы (`time_diff`), наличие ответа (`is_reply`), наличие пунктуации в конце реплики, объединенный контекст диалога и последнее сообщение
- Обучен `CatBoostClassifier` с нативной обработкой текстовых признаков (`text_features`) и остановкой по переобучению (`early_stopping_rounds=50`)
- Выполнена оптимизация порога вероятности на валидационной выборке под целевую метрику $F_{0.5}$ (итоговый результат на валидации: `0.7072` при пороге `0.57`)
